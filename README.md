# College Event Feedback Analysis

## 📊 Project Overview

This project focuses on analyzing feedback collected from a college event using **Microsoft Power BI**.

The main goal of the project is to turn raw event feedback into meaningful insights that can help understand how students experienced the event. The dashboard presents the feedback in an interactive and easy-to-understand way, making it easier to identify overall satisfaction, common opinions, and areas that could be improved in future events.

## 🎯 Objectives

* Analyze feedback collected from the college event.
* Understand the overall satisfaction of participants.
* Identify positive and negative feedback patterns.
* Compare responses across different feedback categories.
* Present the results through interactive Power BI visualizations.
* Help event organizers make better decisions for future events.

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Data Visualization**
* **Data Cleaning & Transformation**

## 📈 Dashboard

The Power BI dashboard provides an interactive view of the collected event feedback.

It allows the data to be explored through different visualizations and filters, helping users quickly understand the overall response and identify important patterns in the feedback.

### Key Analysis Areas

* Overall event feedback
* Participant satisfaction
* Feedback category analysis
* Response distribution
* Positive and negative trends
* Areas for improvement

## 🔄 Project Workflow

The project follows a simple data analysis workflow:

**Raw Feedback Data → Data Cleaning → Data Transformation → Analysis → Power BI Dashboard → Insights**

### 1. Data Preparation

The collected feedback data was prepared for analysis by checking the available responses and organizing the data into a suitable structure.

### 2. Data Transformation

Power Query was used to clean and transform the data so that it could be used effectively for visualization and analysis.

### 3. Data Analysis

Power BI and DAX were used to create calculations and analyze the feedback from different perspectives.

### 4. Dashboard Development

The processed data was converted into interactive charts, visuals, and summary information to make the results easier to understand.

## 💡 Key Takeaway

The project demonstrates how Power BI can be used to convert simple feedback data into an interactive analytical report.

Instead of looking through individual responses manually, the dashboard provides a visual summary that helps identify patterns and understand participant feedback more quickly.
